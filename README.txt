SAFE REPLACEMENT WEBSITE PACKAGE

Included:
- index.html: responsive informational demo page
- favicon.svg: generic lightning favicon

Important:
- This is intentionally NOT an official Meralco payment portal.
- It does not collect personal data, card details, e-wallet details, or payments.
- It does not generate payment receipts.
- The old QR image (88638.jpg) is intentionally not included because its destination and authorization could not be verified.

HOW TO DEPLOY ON GITHUB (Android):
1. Download and extract this ZIP on your phone.
2. Open your repository: https://github.com/stabilizerofficial2026-hash/Meralco-Service
3. Replace the repository's index.html with this package's index.html.
4. Upload favicon.svg to the repository root.
5. Delete the old 88638.jpg only if you confirm it is no longer used anywhere.
6. Commit the changes, then wait for your hosting deployment to finish.

If GitHub says you do not have permission, reconnect GitHub with write access to this repository. No repository changes were made by creating this ZIP.
